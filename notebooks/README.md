# Notebooks

Each `<id>.ipynb` here is our own hands-on notebook for one Detailed lesson (SPEC-013 FR-016).
The lesson's "Open in Colab" button opens it from this repository.

- English only. Code comments and outputs stay English.
- Only libraries Colab has by default. No network calls except Colab's own.
- Owner-approved in `content/review/en.json` (`go run ./cmd/review -lang en`).
- Learner material: it runs only in the learner's own Colab session. Nothing in the build,
  server or app runs it (DC-10).
