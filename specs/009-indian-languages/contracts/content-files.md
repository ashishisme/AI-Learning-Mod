# Content file contracts

Hashes are lowercase hex SHA-256 of the file bytes, unless stated otherwise. All files are UTF-8 JSON.

## `public-content/languages.json` (committed)

```json
{ "languages": [ { "code": "hi", "name": "हिन्दी", "speechLang": "hi-IN", "status": "hidden" } ] }
```

English is implicit. `status` is `hidden` or `approved`. The gate rejects `approved` unless the ledger check and, from B4, the narration check pass.

## Layout per language

```text
public-content/lang/<code>/index.json                      # generated by ingest -lang
public-content/lang/<code>/lessons/<id>.json               # generated (base, from upstream)
public-content/lang/<code>/lessons/<id>.junior.json        # committed (adaptive)
public-content/lang/<code>/lessons/<id>.plain-english.json # committed (adaptive)
public-content/assets/<hash>.<ext>                         # shared asset store (translated images join it)
public-content/audio/<code>/manifest.json                  # generated by narrate
public-content/audio/<code>/<lessonId>/<mode>/<trackId>-<persona>.mp3
web/src/i18n/<code>.json                                   # committed (UI)
web/src/data/quizzes/<code>.json                           # committed
content/glossary/<code>.json                               # committed
content/voices/<code>.json                                 # committed
content/review/<code>.json                                 # committed (ledger)
```

## Lesson and quiz files

These have the same JSON shape as the English file of the same name. Translations change only string values in these allowlisted fields:

- **adaptive** (every learner-visible string; the code list is `Translatable` in `internal/i18n/parity.go`): `title`, `mascot.name`, `mascot.greeting`; in `sections[]`: `heading`, `chipQuote`, `bodyMarkdown`, `analogy.metaphorName`, `analogy.description`, `jargonBuster[].term`, `jargonBuster[].simpleExplanation`, `diagram.caption`, `diagram.alt`, `diagram.content`, `diagram.steps[]`, and the `interactiveWidget` texts (`title`, `instruction`, `goal`, `scaffold`, `predictionPrompt`, `successMessage`, `hints[]`, `scenario.userPrompt`, `scenario.terminalA`, `scenario.terminalB`, `scenario.explanation`); `miniQuiz[].question`, `miniQuiz[].options[]`, `miniQuiz[].praise`, `miniQuiz[].explanation`; `teachBack.prompt`, `teachBack.options[]`, `teachBack.explanation`. Never translated: `lessonId`, `mode`, `sections[].id`, every `type`, `mascot.avatar`, `scenario.correctAnswer`, numbers and booleans. (Corrected 2026-11-03 in B2: the first draft named a non-existent `intro` and left out the jargon, diagram and widget text.)
- **quiz** (per `LessonQuiz` in `web/src/data/quizzes.ts`): `title`, `description`, `questions[].prompt`, `questions[].options[]` (strings), `questions[].rationale`, `questions[].hintKeyword`. Never translated: `lessonId`, `questions[].id`, `correctIndex`.
- **Never translated (all kinds):** IDs, `lessonId`, `mode`, numbers, booleans, URLs, code spans and fenced code. A `§` and the text after it in an existing citation is translated only as part of its heading.

## `web/src/i18n/<code>.json`

```json
{ "home.title": "…", "lesson.notTranslated": "यह हिस्सा अभी हिन्दी में उपलब्ध नहीं है।", "quiz.score.one": "…", "quiz.score.other": "…" }
```

- Keys are flat and dotted.
- Variables are written as `{name}`.
- Plurals use `.one` and `.other` (plus `.zero`, `.two`, `.few` and `.many` if a language needs them).
- `en.json` is the reference: every key in it must exist in each approved language.

## `content/review/<code>.json` (ledger)

```json
{ "language": "hi", "entries": [
  { "path": "public-content/lang/hi/lessons/1-intro.junior.json", "kind": "adaptive",
    "sourceHash": "<sha256 of public-content/lessons/1-intro.junior.json>",
    "translationHash": "<sha256 of the translated file at approval>",
    "status": "approved", "reviewer": "<name or handle>", "date": "2026-11-20" } ] }
```

- **`kind: base`**: `sourceHash` is the hash of the upstream translated README at the pinned SHA, and `translationHash` is the hash of the generated lesson JSON. Both are deterministic for a pinned commit.
- **Required entries**: every English adaptive lesson, base lesson, quiz set and the UI catalogue must have an entry for each approved language.

## `public-content/audio/<code>/manifest.json` (generated by `cmd/narrate`)

Served at `/api/audio/<code>/…` for approved languages only, behind the session gate like the lessons.

```json
{ "language": "hi", "generatedAt": "2026-11-25T10:00:00Z",
  "tracks": { "1-intro/junior/section-what-is-ai": { "chip": { "file": "1-intro/junior/section-what-is-ai-chip.mp3", "hash": "<sha256(voice|rate|pitch + '\\n' + text)>", "bytes": 182344 } } } }
```

- **Track keys**: `<lessonId>/<mode>/<trackId>`. Track IDs are the UI's narration button IDs: `intro-guide-note`, `section-<id>` and `chip-mascot-greeting` (a lesson's own greeting), and `chip-mascot-greeting` under `global/` for the default greeting.
- **Text rule (shared by UI and narrate)**:
  - A section is `heading + ". " + (chipQuote ? chipSays + chipQuote + ". " : "") + bodyMarkdown`.
  - `chipSays` comes from the UI catalogue (`narration.chipSays`). In English it is `"Chip says: "`.
  - Markdown is then stripped by the rules in `speechService.ts`: links become their text, the characters `*_#`~>` are removed, HTML tags are removed, and list numbering is kept.
